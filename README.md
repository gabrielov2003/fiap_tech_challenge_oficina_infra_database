# fiap_tech_challenge_oficina_infra_database

Infraestrutura como código (Terraform) do banco de dados gerenciado utilizado pela aplicação da oficina.

Provisiona o banco de dados consumido pelo repositório `fiap_tech_challenge_oficina_api` e, para consulta de clientes, pelo repositório `fiap_tech_challenge_oficina_auth_lambda`.

Este README será atualizado com a escolha do banco de dados, justificativa técnica, diagrama ER, tecnologias utilizadas e instruções de provisionamento conforme o desenvolvimento avançar.
